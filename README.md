# AARMBH MEDIA — website

Single-page site for AARMBH MEDIA, an event production house in Delhi NCR (concerts, weddings, summits and brand launches).

## Files

| File | Purpose |
|---|---|
| `index.html` | The page |
| `styles.css` | Design system: one palette with Day and Dark themes, layout, reveal effects |
| `script.js` | Interactions and scroll animation (GSAP + ScrollTrigger, Lenis) |
| `animo-cover-ring-720p.mp4` | Showreel, also used for the vertical reels |
| `logo-concepts.html` | 18 logo concepts for the brand |
| `docs/competitor-analysis.md` | Competitor research and design direction |

## Run locally

Open `index.html` in a browser, or serve the folder with any static server so video seeking works, for example:

```bash
npx serve .
```

## Before launch

Replace the placeholders: phone number (`+91 99999 99999`), stock photos, sample testimonials and stats, social and Privacy/Terms links, and the reels with real 1080p vertical clips.
